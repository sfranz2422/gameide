# Backups of built games

Games with their pictures, ready to Import from GameIDE's front page, with the
high score code in. These hold art that isn't anywhere else in this repository
(the teacher's Gemini pictures for Mystery, Under the Lights and Greymire), and
their builds can't remake them without it.

To change their code, patch a copy rather than rebuilding:

    python3 showcase/patch_zip.py showcase/greymire COPY_OF_ZIP

**Thornwood is not here, on purpose.** Anokolisa's terms say the art isn't to be
handed out, so the repository never holds it (see ../README.md).
